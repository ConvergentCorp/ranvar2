ranvar is a probabilistic modelling tool that models probabilistic concepts using micro monte carlo simulations. The underlying data structure is a T-Digest that models probabilistic distributions. This builds on previous attempts I've made at similar libraries. In the past I've used a custom virtual machine to evaluate Python tree structures using a custom DSL implementation. In this version, instead of a virtual machine this version will use a custom decorator that will use cython to compile inline functions and wrapping them in a monte carlo executor.
